# Contributing to EggScan

First of all – thank you for wanting to help improve EggScan! 🥚🔍

EggScan is a GPL-3.0 licensed project focused on being:
- Simple to install
- Safe to upgrade
- Easy to understand and extend

Contributions are welcome, but please read this first.

---

## 🛠 Ways to contribute

You can help by:

- Reporting bugs
- Suggesting improvements
- Improving UI/UX
- Fixing typos or documentation
- Submitting code changes (Pull Requests)

---

## 🐛 Reporting bugs

If you find a bug:

1. Check if it already exists in **Issues**
2. If not, create a new issue and include:
   - EggScan version
   - What you expected to happen
   - What actually happened
   - Any relevant logs or screenshots

---

## ✨ Feature requests

Feature ideas are welcome, but keep in mind:
- EggScan aims to stay lightweight
- Features should fit the existing scope

Please open an issue first before starting larger changes.

---

## 💻 Code contributions

### Workflow

1. **Fork** the repository
2. Create a branch from `main`
3. Make your changes
4. Submit a **Pull Request**

### Guidelines

- Keep changes focused (one feature or fix per PR)
- Do not change the license
- Do not remove attribution
- Follow the existing code style
- Avoid unnecessary refactors

---

## 🧪 Testing

Before submitting a PR:
- Test fresh install using `install_eggscan.sh`
- Test upgrade from a previous version if applicable
- Make sure existing functionality still works
